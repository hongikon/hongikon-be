# 개인정보처리방침 추가 초안 — 물어보기(챗봇) 대화 기록

> 물어보기를 운영(학생에게 공개)에서 켜기 **전에** 앱·웹 개인정보처리방침(프론트 `src/constants/legalText.ts`)에 반영한다.
> 지금(웹 /dev/ask, 개발용 암호키)은 운영진 시험용이라 반영 전이다. 문구는 실제 동작과 맞춰 고친 뒤 쓴다.

## 수집 항목·목적·보관 기간 표에 추가
| 구분 | 항목 | 목적 | 보관 기간 |
|---|---|---|---|
| 물어보기(챗봇) | 질문 내용, 챗봇 답변, 답의 근거 안내, '해결됐나요' 응답, 이용 시각, 대화 구분용 임의 번호 | 답변 제공, 답변 품질 개선, 서비스 오류 분석 | 수집일로부터 1년 후 파기 |

- 질문 속 학번·휴대전화번호·이메일·주민등록번호 형태는 저장 전에 가린다. 회원 계정·IP 주소와 연결해 저장하지 않는다.
- 물어보기에 개인정보를 입력하지 말아 달라는 안내를 화면에 둔다.

## 처리 위탁·국외 이전에 추가
| 받는 자 | 이전 국가 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|---|
| Anthropic, PBC | 미국 | 물어보기 질문 내용, 직전 대화(질문·답) | 질문에 맞는 학교 안내를 고르고 답변 문장 작성 | Anthropic 의 API 데이터 보관 정책에 따름(반영 전 확인) |

- 전송 시점·방법: 질문할 때마다 암호화된 통신(HTTPS)으로 전송.
- 국외 이전을 원하지 않으면 물어보기를 쓰지 않으면 된다(다른 기능 이용에는 영향 없음).

## 확인할 것
- Anthropic API 의 데이터 보관·학습 사용 여부(현재 정책)를 확인해 '보유 기간' 칸을 채운다.
- 운영 `.env` 의 `ASK_LOG_RETENTION_DAYS`(기본 365)와 방침의 보관 기간을 맞춘다.
